MakaMap is a standalone, free and open-source companion tool for MakaMek, a turn-based mech combat board game. Use it to design custom battlefields that you can import into MakaMek or print it and play on it with basically any board/tabletop game that uses hex maps.

Features

- Visual map design: an intuitive graphical interface for creating hex-based maps
- Terrain types: support for various terrain types (clear, woods, rough, water, etc.)
- Map validation: built-in validation to ensure maps are compatible with MakaMek
- Import/export: save and load maps in MakaMek-compatible formats
- PDF export: save a map as a PDF file
- No account, no ads, no tracking: the app is fully offline and collects no data
