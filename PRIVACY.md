# Privacy Policy

Effective date: August 5, 2026

MakaMek Map Editor ("the App", listed on Google Play as **MakaMap**) is a free,
open-source hex map editor companion for the MakaMek tabletop wargame, developed
and published by Anton Makarevich ("the Developer"). This policy describes what
information the App processes. **The App does not collect personal data.**

## Information the App collects

The App does not collect, store, or transmit any personal, sensitive, or
identifying data. It contains no analytics and no advertising SDKs.

### Network connections

On first launch, the App downloads terrain/biome data from the GitHub
repository `anton-makarevich/MakaMek` through the GitHub API
(`api.github.com`). As with any request to a web server, GitHub's servers see
the user's IP address when this download happens; this processing is ephemeral
and the IP address is not retained or stored by the App or the Developer. No
other information — no identifiers, no device data, no personal or sensitive
data — is sent. After this
one-time download the App works fully offline; later launches use the locally
cached data.

## Data stored on the device

- **Maps**: maps created by the user are saved only where the user chooses,
  through the operating system's save/open dialogs. Map files remain on the
  user's device and are under the user's control.
- **Terrain cache**: the downloaded terrain/biome data is cached in the App's
  storage area on the device. It can be removed by clearing the App's data or
  uninstalling the App.

The App does not access any other files on the device.

## Accounts and deletion

The App requires no account. Because the Developer neither collects nor stores
any personal data, there is nothing for the user to delete or to request the
deletion of. All App data resides on the user's device.
